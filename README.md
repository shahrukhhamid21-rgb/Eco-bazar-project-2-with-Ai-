# Ecobazar — Grocery Store Frontend

A responsive grocery storefront built with HTML5, CSS3, JavaScript and Bootstrap 5.

## Run locally
1. Extract the ZIP.
2. Open the `ecobazar-project` folder in Cursor or Google Antigravity.
3. Open `index.html` in a browser, or run it with the VS Code Live Server extension.

## Features
- Responsive navigation and hero section
- Product categories and product cards
- Live product search, category filters and price sorting
- Add-to-cart, quantity controls, remove item and cart subtotal
- Wishlist toggles and counters
- Newsletter demo interaction and toast notifications

## Project structure
- `index.html` — page structure
- `css/style.css` — custom styling and responsive layouts
- `js/app.js` — product data and interactions

## Notes
This is a frontend demo. Cart and wishlist data live in browser memory and reset on refresh. Checkout and newsletter are demo interactions; no backend, authentication or payment gateway is connected. Product photos load from Unsplash and Bootstrap loads from CDN, so an internet connection is needed for those assets.
